# Roadmap — Studio Cleison Cortes

## Fase 1 — Fundação
- [x] Banco de dados, permissões (admin/barbeiro), regras de agenda no servidor
- [x] Design system (preto/verde-limão, logo)
- [ ] Login da equipe com celular + senha; criação do primeiro admin

## Ajustes pedidos pelo dono
- [ ] Cancelamento até 1h antes
- [ ] Agendamento online entra direto como Confirmado
- [ ] Cliente escolhe barbeiro específico (todos aparecem, mesmo cheios)
- [ ] Barbeiro fecha a própria agenda do dia
- [ ] Comissão % por barbeiro só sobre cortes; produto é da barbearia
- [ ] E-mail ao admin a cada agendamento (precisa de domínio de e-mail)

## Fase 2 — Administração
- [ ] Dashboard com indicadores reais
- [ ] Barbeiros (cadastro, foto, horários, serviços, conta de acesso, comissão)
- [ ] Serviços (cadastro, foto)
- [ ] Configurações (dados, horários, regras de agendamento)
- [ ] Agendamentos (lista + ações de status)
- [ ] Agenda visual diária/semanal/mensal + agendamento manual

## Fase 3 — Área pública

- [ ] Fluxo de agendamento + WhatsApp
